## Contributing to Oredlab

Thanks for taking the time to contribute to Oredlab!

Whether you want to fix a bug, improve the code, suggest a new feature, or improve the documentation, your contributions are welcome.

How to Contribute

## Report a Bug

If you find a bug, open an issue on GitHub.

Please explain what happened, what you expected to happen, and how to reproduce the problem. Add screenshots or error messages if they help explain the issue.

For security issues, follow the instructions in "SECURITY.md" (SECURITY.md) instead of creating a public issue.

## Suggest a Feature

Have an idea to improve Oredlab? Open a GitHub issue and explain what you want to add and why it would be useful.

Please check existing issues first to avoid duplicate suggestions.

## Make Changes to the Code

If you want to contribute code:

1. Fork the repository.
2. Clone your fork to your computer.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear message.
6. Push your branch to your fork.
7. Open a pull request to the main Oredlab repository.

## Before Submitting

Please make sure that:

- Your changes work as expected.
- Existing features are not broken.
- Your code is easy to understand.
- You do not include passwords, API keys, tokens, or other secrets.
- You explain what you changed and why in your pull request.

## Code Style

- Keep the existing code structure and style where possible.
- Use clear names for variables, functions, and files.
- Avoid unnecessary changes unrelated to your contribution.
- Add comments when they help explain something that is not obvious.

## Pull Requests

Before opening a pull request, check whether a similar change is already being worked on.

In your pull request, explain what you changed, why you made the change, and how you tested it.

Your changes may be reviewed before they are merged. You may be asked to make adjustments.

## Need Help?

If you are unsure about something, open a GitHub issue and ask. Please provide enough details for others to understand your question.

Thanks for helping make Oredlab better!
